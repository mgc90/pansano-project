# 🍞 Pan Sano

My **first real project**, started in **March 2024**. It was a **self-directed
learning** experience rooted in a **real domain**: the Pan Sano bakery. I built
it while involved in the actual business, which forced honest **product
thinking** — decisions shaped by the venture's real needs, not just the code.

With it I learned the fundamentals of **functional React**: components, state,
hooks and routing.
